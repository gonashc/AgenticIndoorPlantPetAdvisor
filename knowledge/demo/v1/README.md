# USDA and CDC demo knowledge pack

This pack contains concise, source-derived demo summaries. It does not contain copies of the
downloaded PDFs or the full USDA checklist. Every record is tagged `DEMO_UNVERIFIED`, so the
ingestion command accepts it only in `local` or `test` environments.

The pack supports plant identity; general dog and cat selection and care; and pet hygiene, food
safety, tick checks, and emergency preparation. It does **not** establish plant toxicity,
species-specific indoor plant care, profile-specific animal behavior, costs, or local availability.

Review `manifest.json` and the files under `sources/` before ingestion. The raw attachment hashes
and duplicate decision are recorded in `SOURCE_INVENTORY.md`.
